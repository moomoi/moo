## Search

Press the hotkey and type. Apps, commands, files, answers and plugin commands all rank together, and the things you pick most often move up. Results update on every keystroke.

| Key | Does |
| --- | --- |
| [[↑]] [[↓]] or [[⌃ N]] [[⌃ P]] | Move the selection |
| [[Return]] | Open or run the selection |
| [[Tab]] | Ask AI about what you typed, or fill a command's arguments |
| [[Esc]] | Back, then close |
| [[⌘ K]] | Action panel for the selected row |

## Categories

Like Spotlight, four categories are one key away:

| Key | Opens |
| --- | --- |
| [[⌘ 1]] | Applications |
| [[⌘ 2]] | Files |
| [[⌘ 3]] | Actions |
| [[⌘ 4]] | Clipboard |

## Try these

- `safari`: open an app
- `12% of 3400`: an [instant answer](/docs/calculator)
- `left half`: a [window layout](/docs/windows)
- `lock`: a [system command](/docs/system)
- `why is the sky blue` then [[Tab]]: [Ask AI](/docs/ask-ai)

See the [keyboard reference](/docs/keyboard) for every key.
