## Where moo lives

moo runs as a menu bar app with no Dock icon. Click the menu bar icon to show the launcher. Right-click it for **Settings…** and **Quit**.

## Permissions

moo asks for a permission only the first time a feature needs it:

| Permission | Asked when | Used for |
| --- | --- | --- |
| Accessibility | Your first window command or text snippet | Moving windows, `{selection}` in shortcuts, expanding snippets as you type |
| Contacts | You open **Search Contacts** | Finding people |

Grant them in **System Settings › Privacy & Security**.

> **Note** If you started moo from a terminal, macOS checks the terminal's permissions instead of moo's. Started from Finder or at login, moo needs its own entry.

## Next

Press the hotkey and start typing. [The hotkey](/docs/hotkey) explains which keys moo picks and how to change them.
