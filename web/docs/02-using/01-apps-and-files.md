## Apps

Type part of an app's name. Matching is fuzzy, so `vsc` finds Visual Studio Code. [[⌘ 1]] lists every application, and [[⌘ L]] switches between a grid and a list.

**Running Apps** lists what's open. [[⌘ H]] hides the selected app.

## Files

File names come from moo's own index, which stays current as files change, so results are instant. [[⌘ 2]] or **Search Files** searches files only, including words inside documents.

| Key | On a file |
| --- | --- |
| [[Return]] | Open |
| [[⌘ Y]] | Quick Look |
| [[⌘ R]] | Show in Finder |
| [[⌘ O]] | Open with another app |
| [[⌥ Return]] | Copy its path |

## More sources

- **Define Word**: the Mac's dictionary, with pronunciation, senses and origin.
- **Search the Web**: suggestions from your search engine as you type.
- **Search Contacts**: people from Contacts, after you allow access.
- **Recent Searches**: what you searched for before.
