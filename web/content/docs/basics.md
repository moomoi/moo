## Search

Press the hotkey and type. Apps, commands, files, answers and plugin commands all rank together, and the things you pick most often move up. Results update on every keystroke.

| Key | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>⌃</kbd> <kbd>N</kbd> <kbd>⌃</kbd> <kbd>P</kbd> | Move the selection |
| <kbd>Return</kbd> | Open or run the selection |
| <kbd>Tab</kbd> | Ask AI about what you typed, or fill a command's arguments |
| <kbd>Esc</kbd> | Back, then close |
| <kbd>⌘</kbd> <kbd>K</kbd> | Action panel for the selected row |

## Categories

Like Spotlight, four categories are one key away:

| Key | Opens |
| --- | --- |
| <kbd>⌘</kbd> <kbd>1</kbd> | Applications |
| <kbd>⌘</kbd> <kbd>2</kbd> | Files |
| <kbd>⌘</kbd> <kbd>3</kbd> | Actions |
| <kbd>⌘</kbd> <kbd>4</kbd> | Clipboard |

- `12% of 3400`: an [instant answer](/docs/calculator)
