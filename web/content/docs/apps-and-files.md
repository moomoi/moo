## Apps

Type part of an app's name. Matching is fuzzy, so `vsc` finds Visual Studio Code. <kbd>⌘</kbd> <kbd>1</kbd> lists every application, and <kbd>⌘</kbd> <kbd>L</kbd> switches between a grid and a list.

**Running Apps** lists what's open. <kbd>⌘</kbd> <kbd>H</kbd> hides the selected app.

## Files

File names come from moo's own index, which stays current as files change, so results are instant. <kbd>⌘</kbd> <kbd>2</kbd> or **Search Files** searches files only, including words inside documents.

| Key | On a file |
| --- | --- |
| <kbd>Return</kbd> | Open |
| <kbd>⌘</kbd> <kbd>Y</kbd> | Quick Look |
| <kbd>⌘</kbd> <kbd>R</kbd> | Show in Finder |
| <kbd>⌘</kbd> <kbd>O</kbd> | Open with another app |
| <kbd>⌥</kbd> <kbd>Return</kbd> | Copy its path |

## More sources

- **Define Word**: the Mac's dictionary, with pronunciation, senses and origin.
- **Search the Web**: suggestions from your search engine as you type.
- **Search Contacts**: people from Contacts, after you allow access.
- **Recent Searches**: what you searched for before.
