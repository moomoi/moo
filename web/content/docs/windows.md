Window commands act on the window behind the launcher, the one you were just using. Type the layout's name: `left half`, `max`, `next display`.

| Layouts | |
| --- | --- |
| Halves | Left Half, Right Half, Top Half, Bottom Half |
| Quarters | Top Left, Top Right, Bottom Left, Bottom Right Quarter |
| Thirds | First Third, Center Third, Last Third, First Two Thirds, Last Two Thirds |
| Size | Maximize Window, Almost Maximize, Maximize Height, Center Window, Reasonable Size |
| Displays | Next Display, Previous Display |
| Undo | Restore Window |

The first window command asks for Accessibility permission.

> **Tip** Bind the ones you use most to hotkeys, such as `moo hotkey add ctrl+alt+left moo:window:left-half`. Command ids are listed by `moo list commands`.
